# Homebrew Tap

Personal Homebrew tap for VMark and other tools.

## Installation

```bash
brew tap xiaolai/tap
brew install --cask vmark          # or any cask listed below
```

## Available Casks

- **vmark** - A modern Markdown editor built with Tauri
- **xiaolaidict** - A menu-bar dictionary for macOS (macOS 27+, Apple Silicon)

## Updating

```bash
brew update
brew upgrade --cask vmark
```
